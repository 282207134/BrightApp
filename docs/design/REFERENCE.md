通过 Flutter design-to-code 获取首页结构，再结合各画板截图、文本、颜色和图片实现页面。批量生成超时后单画板获取成功，部分临时资源 404 改用节点导出和 imageHash 原图读取。最终资源全部本地化，没有 localhost 依赖。

保留白底、粉色强调色、Josefin Sans / Lato、商品大卡片、头像照片、渐变菜单、靛蓝聊天和统计图表等主要视觉特征。四张初始视觉参考在本目录 `*_reference.png`。

原稿缺少部分按钮文字，已补齐明确动作；固定画板布局改为安全区和可滚动内容。系统键盘使用实际输入状态，不制作键盘截图。原本纯色或缺图的画板保持其占位视觉。完整设计稿截图未作为应用页面使用。

地图是本地绘制的示意地图；认证、相机、扫码、测脚、音视频和支付为明确标识的交互演示。地址、订单确认、成功页与订单记录补齐购物闭环。
