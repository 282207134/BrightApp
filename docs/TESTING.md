# 验证记录

验证日期：2026-10-21（Asia/Tokyo）。环境为 Flutter 3.41.6 / Dart 3.11.4，Xcode 26.0.1，iPhone 17 Pro / iOS 26.0 模拟器。

| 检查 | 结果 |

| `flutter test` | 105 项通过 |

## 模拟器验证

端到端测试实际运行在 iPhone 模拟器中，测试场景包含：

1. 空登录输入显示错误；合法邮箱和演示密码进入购物首页。
2. 搜索 HUSTLE 只返回相应商品。
3. 未选尺码不能加购；选择尺码后可加购。
4. 测脚演示的示例尺码逐级返回商品页面。
5. 加购后进入购物袋，数量增加 / 减少和合计同步更新。
6. 选择免费 / 标准配送，地址、演示卡片和订单确认可顺序完成。
7. 下单金额与确认金额一致，清空购物袋并生成历史订单。
8. 通知清空、收藏、资料与空购物袋页面正常呈现。
9. 聊天输入发送后出现新消息，并自动滚动至最新消息。
10. 接受连接请求后显示 Accepted。
11. 服饰详情商品加入共享购物袋。
12. 打开 12 个模块列表，并逐一进入全部 97 个画板预览。

截图包括 97 个画板预览、12 个模块列表、模块目录和 31 个购物流程页面 / 状态，共 141 张 PNG。详见 [SCREENSHOTS.md](SCREENSHOTS.md)。

## 实际修复

- 上级路径末尾空格被 Xcode 截断：将工程置于 `bright_app/` 子目录。
- 门店地图收起面板溢出：调整地图与面板高度比例。
- 扫描结果返回丢失：采用导航结果逐级返回，避免替换路由提前结束等待。
- 发送聊天消息后被列表底部遮住：发送后收起键盘并滚动到最新消息。
- 截图残留提示条：截图前移除临时提示条。
- 深色资料页标题对比度：标题使用浅色。
- 全量字体和图片本地化，图片压缩为 WebP，资源目录约 3.6 MB。

本轮实际运行验证覆盖 iOS 模拟器；Android / Web 工程已保留，未进行对应设备或浏览器的运行验收。
